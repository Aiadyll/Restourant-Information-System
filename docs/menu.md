# Мейрамхана мәзірі

## Жобаның мәзір модулі

Бұл модуль мейрамхана тағамдарын басқаруға арналған.

## Негізгі функциялар

1. Тағамдар тізімін көрсету.
2. Тағамдарды категория бойынша бөлу.
3. Тағам бағасын көрсету.
4. Жаңа тағам қосу.
5. Тағам туралы ақпаратты өзгерту.
6. Тағамды мәзірден өшіру.

## Категориялар

- Бургерлер
- Пицца
- Сусындар
- Десерттер
