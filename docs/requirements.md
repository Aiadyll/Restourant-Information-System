# Restaurant Information System

## Жобаның мақсаты
Мейрамханадағы тапсырыстарды басқаруға арналған ақпараттық жүйе құру.

## Функционалдық талаптар
1. Пайдаланушыларды тіркеу.
2. Мәзірді қарау.
3. Тағамдарға тапсырыс беру.
4. Тапсырыс мәртебесін бақылау.
5. Әкімші арқылы мәзірді басқару.

## Қолданылатын технологиялар
- HTML
- CSS
- SQL
