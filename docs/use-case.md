# Restaurant Information System

## Use Case диаграммасы

### Акторлар
1. Клиент
2. Әкімші
3. Аспаз

### Клиент функциялары
- Жүйеге тіркелу
- Жүйеге кіру
- Мәзірді қарау
- Тағам таңдау
- Тапсырыс беру
- Тапсырыс күйін бақылау

### Әкімші функциялары
- Тағамдарды қосу
- Тағамдарды өзгерту
- Тағамдарды өшіру
- Тапсырыстарды қарау

### Аспаз функциялары
- Тапсырыстарды қабылдау
- Тағам дайындау
- Тапсырыс күйін жаңарту
